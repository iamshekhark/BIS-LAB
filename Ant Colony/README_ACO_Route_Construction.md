# Ant Colony Optimization (ACO): Probability-Based Route Construction

## 1. Overview

This project demonstrates the route-construction mechanism of Ant Colony
Optimization (ACO) for a delivery robot visiting 10 warehouse locations.
Each ant selects its next unvisited city using a probability based on
pheromone strength and distance. Every generated route visits each city
exactly once.

## 2. Problem Statement

A delivery robot must visit 10 different warehouse locations without
visiting any location more than once. It uses pheromone information and
the distance between locations to decide its next destination. Implement
ACO route construction, calculate the probability of selecting the next
unvisited city, and ensure every generated route visits all cities
exactly once.

## 3. Problem Objective

-   Implement probability-based route construction using ACO.
-   Calculate next-city selection probabilities using pheromone and
    distance.
-   Ensure every city is visited exactly once in each route.
-   Calculate each complete tour distance, including the return to the
    starting city.

## 4. Selection Probability

For an ant at city `i`, the probability of moving to an unvisited city
`j` is:

\[ P\_{ij} = `\frac{(\tau_{ij})^\alpha(\eta_{ij})^\beta}`{=tex}
{`\sum`{=tex}*{k
`\in `{=tex}U}(`\tau`{=tex}*{ik})\^`\alpha`{=tex}(`\eta`{=tex}\_{ik})\^`\beta`{=tex}}
\]

Where: - `P_ij` = probability of selecting city `j` from city `i`. -
`tau_ij` = pheromone value on the path from city `i` to city `j`. -
`eta_ij` = heuristic value, calculated as `1 / distance(i, j)`. -
`alpha` = influence of pheromone. - `beta` = influence of distance. -
`U` = set of cities not yet visited.

The probabilities of all eligible next cities add up to 1.

## 5. Algorithm / Working

1.  Create a distance matrix for the 10 cities.
2.  Initialize all pheromone values.
3.  Set the ACO parameters `alpha` and `beta`.
4.  Select a random starting city for each ant.
5.  Create a list of all unvisited cities.
6.  Calculate the selection probability for every unvisited city.
7.  Select the next city according to those probabilities.
8.  Add the selected city to the route and remove it from the unvisited
    list.
9.  Repeat until all 10 cities have been visited.
10. Calculate the total tour distance, including the return to the
    starting city.

## 11. Research Paper

**Title:** Random Pairwise Competition Based Ant Selection for Pheromone
Updating in Ant Colony Optimization

-   **Conference:** 2023 IEEE International Conference on Systems, Man,
    and Cybernetics (SMC)
-   **DOI:** `10.1109/SMC53992.2023.10394413`
-   **IEEE Xplore:**
    https://ieeexplore.ieee.org/abstract/document/10394413
-   **DOI link:** https://doi.org/10.1109/SMC53992.2023.10394413

The paper studies an ant-selection strategy for pheromone updating in
ACO and evaluates it on Travelling Salesman Problem instances. It is
relevant background for ACO route optimization. The practical program
demonstrates **route construction and next-city selection probabilities
only**; it does not implement the paper's pairwise ant-selection
strategy or a complete pheromone-update cycle.

## 12. Conclusion

The project demonstrates how ACO constructs routes using pheromone
information and distance-based probabilities. The unvisited-city list
ensures that each generated route contains every city exactly once. This
route-construction mechanism is a building block for a complete ACO
solution to routing and Travelling Salesman Problems.
